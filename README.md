# Deep Learning Project 2024

## Overview
This project aims to solve the problem of SST recognition under cloud occlusion through a UNET framework. Many other networks were tried, but the UNET was the one that yielded the best results. The task was to evaluate the model with respect to the RMSE value, which had to be improved. 

## Requirements
- Python 3.8
- Numpy
- Pandas
- Tensorflow
- Gdown  (this only works in google colab)
